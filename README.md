# Para ti, mi princesa

Página de cumpleaños (14 de octubre): cuenta regresiva con frases y poemas, línea de tiempo de fotos y carta de amor.

## Editar textos, fotos y videos
Todo está en el bloque `CONFIG` al inicio de `script.js`: apodo, carta, frases, poemas, capítulos de fotos (`historia`) y `videos`.
Para agregar videos, crea la carpeta `videos/`, sube los .mp4 (ideal menos de 20 MB cada uno) y agrégalos así:
`videos: [{ src: "videos/1.mp4", texto: "Nuestro primer viaje" }]`

## Publicar en GitHub Pages
1. Repositorio: https://github.com/brian2517/AmorMio (debe ser público).
2. Descomprime el .zip y sube todo su contenido respetando la carpeta `fotos/` (arrastra la carpeta completa a "Upload files").
3. Settings > Pages > Deploy from a branch > rama `main`, carpeta `/ (root)` > Save.
4. En uno o dos minutos queda en https://brian2517.github.io/AmorMio/.
